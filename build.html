How this works Add each part to the run it belongs in

Follow the refrigerant — that is the whole method

  1. Start at the compressor. It is fixed top-left, because that is where a circuit is read from. Everything else follows the refrigerant round the loop and back to it.
  2. Drop a part on the run it belongs in. Aim at a flow arrow — each one is a join in the pipework. Or click a part to add it to the end, then move it with the ▲ ▼ buttons.
  3. Read the analysis. An error means the system would not run. A note means it would run, but a technician would have piped it differently — and it says why.
